# Tarea 3 · Lista de tareas

**Alumno:** Julio César Arias Gaytán  
**Materia:** Programación para Internet

Abre [proyecto-todo/index.html](proyecto-todo/index.html) en tu navegador para ejecutar la aplicación. No necesitas instalar paquetes.

La lista permite editar tareas, asignarles una categoría y una fecha límite, filtrar por estado y categoría, alternar entre modo claro y oscuro y ver una animación antes de eliminar una tarea. Las tareas que vencen hoy o en los próximos tres días se destacan. Las tareas y el tema se guardan en el navegador.

Consulta [LEEME.txt](proyecto-todo/LEEME.txt) para ver los pasos de prueba.

Proyecto basado en [CursoDeJS de Michel López Franco](https://github.com/michel-lopez-franco/CursoDeJS).
